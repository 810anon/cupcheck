# Cup Check

*Covering the essentials since level 1.*

Tracks missing class buffs on your raid frames, and shows a solo frame when you are not in a group. Built for WoW: Forever, also runs on Midnight.

- Icons are children of Blizzard's raid frames and only read state, so they don't taint the default UI.
- Solo frame is its own lookalike, hidden automatically when you join a group.
- `/cupcheck` opens the options window.

## Install

Download from CurseForge, or copy the `CupCheck` folder into `World of Warcraft\_forever_\Interface\AddOns\` (or `_retail_`).
